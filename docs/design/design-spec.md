# 家簿 · 设计规范「手账拼贴」

> 适用：家簿 App（Flutter 实现，先做 Android，将来可出 iOS）。本规范是视觉与交互的唯一依据；与任何原型或截图不一致时，以本文为准。Flutter 技术选型见 [客户端规范](../engineering/client-flutter.md)。

## 一句话

像一本温暖的家庭手账：**纸面、胶带、贴纸、印章**负责“有人情味”，**数字和文字永远端正好读**负责“记账靠谱”。装饰可以歪，信息不歪。

三条硬规则：

1. **列表、表格、带数字的卡片一律水平（0°）**，倾斜只给胶带、贴纸、印章、拍立得照片、主卡片等装饰性元素。
2. **手写字只用于 App 自己写的短文案和日期**（如“原图已保存”“今天 · 10月24日 周六”），**用户输入、金额明细、表单一律用正文字体**。
3. **一套配色，空间只做点缀**：不论在哪个空间，纸面、主色、胶带都不变；当前空间靠顶栏的空间名称和它的点缀色小圆点识别，不整屏换色。

所有正文对比度 ≥ 4.5:1：ink-3 是最浅的可读文字色（对 bg 5.0）；状态色 pos 5.8、neg 6.0、warn 5.7（均对纸面）。贴纸里的图标色对贴纸底均 ≥ 5.9。禁止用透明度把正文调淡（已撤销的卡片除外，那是“失效”状态）。

## 2. 字体

### 2.1 四种字（另加只用于 API key 的等宽字）

| 角色 | App 方案（Flutter） | 用在哪 |
|---|---|---|
| 正文 Sans | 系统字体（不指定 fontFamily，安卓上即系统自带 Noto Sans CJK），不打包 | 所有正文、按钮、表单、列表、用户输入 |
| 标题 Serif | **打包 Noto Serif SC Bold 子集**（OFL-1.1）：常用字 + App 文案 | 页面大标题（家簿 / 总览 / 历史）、卡片标题、区块标题、AI 追问句 |
| 手写数字 Caveat | **打包 Caveat SemiBold**（OFL-1.1，完整 Latin 约 100 KB） | 金额、余额、视力数值、时间、少量英文点缀（My Home Diary / Total / Oct. 24 · Sat / Diary Log） |
| 手写中文 楷 | **打包霞鹜文楷（LXGW WenKai）Medium 子集**（OFL-1.1），内部字体名 “JiabuHand”，见 2.3 | 固定的短文案、日期标签、拍立得说明、空状态 |
| 等宽（只用于 API key） | 系统等宽字体（安卓自带，不打包），令牌 `JiabuType.mono` | 只用于 API key 的明文和开头几位（4.19），方便逐字核对；别处一律不用 |

### 2.3 手写字规则（重要）

- **中文绝不落在 Caveat 上**。负号一律用 U+2212「−」而不是连字符；千分位用英文逗号。所有“数字 + 中文”混排（如“今天 12:36”）必须用“Caveat 优先、楷体兜底”的字体链：数字走 Caveat，中文走楷。
- **楷体只给 App 自己写的固定文案**：副标题、日期标签（今天 / 昨天 / X月X日 周X）、“原图已保存”、“没花完的钱会一直留在各自账户里，按月结转。”、默认个人空间说明（“这里只有你能看到”）、空状态“没有找到符合条件的记录”。用户输入的内容（原始输入、标题、备注）一律用正文 Sans，因为用户可能打出子集里没有的字。
- **带数据的句子不用手写**：例如“眼轴较 4月12日 左 +0.26、右 +0.26 mm”是数据，用 Sans 13 半粗；手写只做“氛围”。
- **楷体子集的生成方式**：
  1. 手写样式的文案统一放在 ARB 文案文件（Flutter 官方的多语言文案格式）里，键名以 `hand` 开头（如 `handOriginalSaved`）。构建时从 ARB 提取这些文案的字符，加上日期需要的字（今天昨天年月日周一二三四五六日）、数字和中文标点，用 fontTools `pyftsubset` 裁剪 LXGW WenKai Medium，输出 `jiabu_design` 包里的 `assets/fonts/jiabu_hand.ttf`。预计几十到几百 KB。
  2. **CI 检查**：手写样式的文案里出现子集外的字，构建失败。
  3. 如果以后要让用户内容也用楷体：改为打包 GB2312 一级常用字（约 3755 字）子集，约 2–3 MB，届时再评估。
- **不在运行时下载字体**：不引入 `google_fonts` 包，也不用 Google Play 的“可下载字体”。许多国内安卓设备没有 Google Play 服务，也访问不了 Google 字体服务。
- **授权**：Caveat、Noto Serif SC、LXGW WenKai 都是 SIL Open Font License 1.1，允许打包进 App 和裁剪。要求：在 App“关于 / 开源许可”页列出字体名与版权，随包附 OFL 全文（Flutter 用 `LicenseRegistry` 登记）；裁剪后的字体不单独作为字体文件分发。霞鹜文楷有保留字体名（“霞鹜”“LXGW”），子集使用内部名（JiabuHand），在许可页写明“基于 LXGW WenKai”。

### 3.1 间距（4 的倍数为主）

| 位置 | 数值 |
|---|---|
| 页面左右边距 | 18（≤380 宽时顶栏左右 14 / 10） |
| 卡片内边距 | 16（记录卡底部操作区 4） |
| 主卡（总结余）内边距 | 24 上 / 20 左右 |
| 卡片之间、格子之间 | 12–14 |
| 区块标题上方 | 30，下方 12 |
| 聊天消息之间 | 6；AI 消息上下 6 / 12 |
| 列表行最小高度 | 66（左右内边距 12–14） |
| 记录卡键值行 | 最小高 30，左标签右数值，中间点线引导，按基线对齐 |

### 3.2 圆角

纸张感 = 小圆角。卡片 3；拍立得 / 便签 2；输入框、搜索框 10–12；筛选 chip 8；回答选项、徽章、按钮全圆角（胶囊）；底部弹层顶部 20；提示条 4；贴纸圆形。

### 3.3 阴影（“纸片浮在桌面上”）

| 层级 | 阴影 | 用于 |
|---|---|---|
| 贴纸级 | 0 1 1.5 rgba(60,40,20,.22) + 0 4 8 -4 rgba(60,40,20,.35) | 贴纸、圆形按钮 |
| 卡片级 | 0 1 1 rgba(60,40,20,.08) + 0 12 20 -12 rgba(60,40,20,.42) | 记录卡、列表纸、格子 |
| 主卡级 | 0 1 1 rgba(60,40,20,.08) + 0 16 26 -16 rgba(60,40,20,.5) | 总结余主卡 |
| 弹层 | 0 -8 30 rgba(0,0,0,.12) | 底部弹层 |

贴纸、选中按钮外圈都有 2–2.5 的**白色描边**（模拟剪下来的贴纸白边）。

### 3.4 倾斜

| 等级 | 角度 | 用在哪 |
|---|---|---|
| 不倾斜 | 0° | **所有含文字行、数字、按钮的容器**：记录卡、资料卡及其内部小卡、用途账户格子、横格列表、负余额提醒便签、底部弹层、提示条、输入栏、表格 |
| 轻微 | ±0.5°–1° | 只含一两句话的“纸片”：我的聊天便利贴（按消息 id 取 −0.72°…+0.72°）、总结余主卡 −0.6°、个人空间说明便签 −0.8°、原始输入便签 −0.6°、回答选项（奇数 −1°、偶数 +0.8°） |
| 明显 | ±2°–8° | 纯装饰与小物件：胶带 ±2.5°–5°、贴纸 −6°、Logo 圆章 −8°、印章 −5°、拍立得 ±2°、家庭资料拍立得卡 ±1.3°、日期胶带 ±1.5° |

角度必须是**确定性**的：同一条记录每次显示同一个角度（用 id 做哈希），不要每次重绘随机。

## 4. 组件

### 4.1 记录卡（聊天里 AI 记好的一笔）

- 纸面卡片，**水平**，最大宽 332，左上角一条胶带（−5°，压住卡片上沿 10px）。
- 第一行：贴纸图标（40 圆）+「支出 · 日常餐饮」（12 粗）+ 手写时间「今天 12:36」+ 右侧记录人（成员显示名，Sans 12，ink-3；已退出成员显示「名字 · 已退出」）。卡片右上角一个 6 圆点小角标，用当前空间点缀色（读屏隐藏）。
- 第二行（整行可点，打开详情，最小高 56）：标题（Serif 19 粗，超长省略）+ 金额（Caveat 40，主色，下半截荧光笔）。
- 键值区：真实账户 / 用途余额（余额为负时变红）/ 标签（# 开头，主色），点线引导，按基线对齐。
- 底部虚线分隔 + 操作：左边「已记录」印章，右边「编辑」「撤销」文字按钮（高 44）。
- 已撤销：纸面变半透明 + 内描边，标题与金额用**一道手绘铅笔划线**（2px，−2.5°，横穿整个值）而不是逐字删除线；印章变灰「已撤销 · 余额已恢复」，操作只剩「恢复」。
- 资料卡（视力检查）：同一外壳，内部左右眼两张小纸片（水平），裸眼视力 Caveat 46；下方一句数据说明用 Sans；操作「原图 / 对比 / 编辑 / 撤销」。
- 调拨卡：标题「备用金 → 教育」，副标题「调拨 · 不动真钱」。

### 4.4 印章（stamp）

高 24，1.8 描边、圆角 5，粗体 12，字距 .08em，−5°，透明度 .92。绿色「✓ 已记录」；灰色「已撤销 · 余额已恢复」。只表达状态，不可点。

### 4.5 拍立得照片

白框 9（底部 34 写说明），2 圆角，±2° 倾斜，顶部居中一条圆点胶带；底部手写说明「✓ 原图已保存」（楷 14）。点击查看原图（底部弹层里原图加 8px 白边、−1.5°）。

### 4.6 便利贴提醒（负余额）

#FFE3DA 底，**水平**，左上角回形针（−12°，灰）。标题红色粗体「教育 当前为 −¥180.00」，说明 13 号，下面一个整宽主按钮「从备用金调拨 ¥180」（高 46，白色外圈 + 内部白色虚线）。

### 4.7 底部导航 + 手绘圈

纸面底栏高 78，上沿是一排半圆“撕纸边”。三项：聊天 / 总览 / 历史（图标 22 + 文字 12）。选中项：图标外套一个**手绘椭圆圈**（主色，2.4 线宽，故意不闭合），文字主色粗体。点击区域整列，≥ 48 高。

### 4.8 空间切换器 SpaceSwitcher

- **顶栏左侧**：8 圆点（空间点缀色，白描边 1.5）+ 空间名称（Serif 16 粗，点缀色，超长省略）+ 小下箭头（ink-3）。整块点击区 ≥ 48 高，水平、不倾斜、无虚线框——它是低调的标题，不是醒目的开关。
- **打开**：底部弹层「我的空间」（胶带把手）。每行高 56：圆点 + 名称 + 右侧当前项 ✓；默认个人空间名称下加一行楷体小字「只有你能看到」。只列出自己在册的空间，不显示任何其他空间的痕迹，也不在列表上标未读数或金额。
- **弹层底部**：「＋ 新建空间」「空间设置」两个文字按钮（高 44）。
- **新建空间**：名称输入 + 8 色点缀色色板（圆 32，选中项白圈 + ✓）。
- **空间设置**：改名、改点缀色；成员列表（显示名 + 角色「所有者 / 成员」）；「邀请成员」（从已有账号中选，v1 无公开注册）；所有者可移除成员、「转让所有者」（从现有成员中选一位，二次确认）；「退出空间」（描边，neg 色文字，二次确认；本机还有没上传的内容时，确认卡里写「有 N 条还没上传，退出后会丢弃」）；「删除空间」（只在所有者且空间里只剩自己时出现，描边，neg 色文字；确认时要输入空间名，确认卡写明「删除后不能恢复」）。最后一位所有者点「退出空间」时，确认卡改为引导：还有别人就先「转让所有者」，只剩自己就「删除空间」。默认个人空间不显示邀请、退出与删除。被别人移出空间后，回到默认个人空间并弹一条提示条（4.14，无「撤回」）「你已不在「空间名」中，本机上的内容已清除」。
- App 打开即进入上次使用的空间；切换后内容淡出淡入，配色不变。历史页的筛选只在当前空间内进行。

### 4.9 聊天气泡

- 我：便利贴（note 色），右对齐，左侧留 56 空白，圆角 2/2/14/2，右下角折角三角，轻微倾斜；下方手写时间。
- AI：不加气泡，直接写在纸上：头像小圆章（主色、星星、−10°）+「家簿助手」，正文 Sans 15/1.7，宽 ≤ 94%。
- 日期分隔：居中一段胶带，上写「今天 · 10月24日 周六」（Caveat + 楷）。

### 4.10 追问（AI 需要补信息时）

AI 先说一句已识别到的内容（正文），再一句追问（Serif 16 粗 + 荧光笔），下方一排胶囊选项（高 44，白底，1.5 描边，交替 ±1°）。点按后先显示“提交中”（被点的胶囊里一个小进度，全部禁用，不提前打 ✓）；服务端确认后：选中项 primary-soft + ✓，其他项变半透明并禁用；**不出现**“我的回答”气泡（回答就记在这张卡上；打字回答时卡片下方多一行 Sans 13 ink-2「你的回答：……」）；AI 在**同一条回复**里接着往下写，记录卡出现在追问卡下方。

选项那一排的最后固定多一个胶囊「输入其他内容」：同样高 44、0°（它是操作入口，不是纸片），白底、1.5 **虚线**描边 line-strong，左侧手绘铅笔图标 16 ink-2，文字 Sans 14 ink-2。确认卡和小表单没有胶囊排，「输入其他内容」放在按钮下方，是一个高 44 的文字按钮（铅笔图标 + Sans 13 primary-text）。点它之后输入栏的变化见 4.18。卡片等待回答期间输入栏锁定（4.18）。

### 4.11 离线状态

| 状态 | 我的气泡 | 状态行 | 操作 |
|---|---|---|---|
| 待上传（已存在本机） | 半透明纸 + 1.8 虚线框，无阴影 | 断云图标 + 「待上传 · 已存在本机」warn 色 | 「重试」胶囊按钮，高 44 |
| 待 AI 处理 | 恢复正常便利贴 | 转圈 + 「待 AI 处理」主色 | 无 |
| 已上传 / 已处理 | 正常 | ✓「已上传」绿色 | AI 随后发出记录卡 |
| 已撤销 | 正常 | 「已撤销」灰色 | — |

联网恢复时弹提示条「网络已恢复，1 条记录已上传」。总览页有「待处理」区块列出同样的条目。

### 4.12 历史页与筛选

- 顶部吸顶：横格搜索框（高 52）+ 横向滚动的筛选 chip（高 44，虚线框；选中变 primary-soft 实底 + 白圈）。chip 顺序：成员、账户、标签、类型…（均在当前空间内）；点 chip 打开底部单选列表（每项高 52，选中项 primary-soft + ✓）。
- 有筛选时出现一行「N 条结果 · 清除筛选」。
- 按天分组：日期写在胶带上（三种胶带轮换，±1.4°），右侧当天支出合计。每组是一张横格纸（左侧红色装订线、蓝色行线），行内：贴纸 + 标题 / 说明 + 右侧金额与手写时间。长标题省略号截断。
- 空状态：放大镜 + 楷体「没有找到符合条件的记录」。

### 4.13 详情弹层

底部弹层（最高 88% 屏），顶部一段胶带当把手，纸面带点阵。内容：类别 → 大金额（Caveat 58，荧光笔）→ 点线分隔的字段表（真实账户、用途账户、记录人（已退出成员标「已退出」）、时间、标签）→ 原图缩略（或原始输入便利贴，Sans）→ 变更记录时间线（手绘小圆圈 + 竖线，时间用 Caveat + 楷）。底部固定操作：「撤销」描边 +「编辑」主色，各占一半，高 48。资料类显示提取数值表和「对比历次检查」。

编辑弹层：金额（Caveat 30 输入）、说明、真实账户 / 用途账户单选 chip（高 44，只列本空间账户）、标签；保存后按差额调整余额并写入变更记录（例：「金额由 68.00 改为 72.00 · 用户A」）。

### 4.14 提示条（snackbar）

深色纸条，**水平**，圆角 4，左右 12 边距，聊天页时浮在输入栏上方（底部 150），其他页在导航上方（92）。文字 14 + 右侧操作「撤回」（主色浅调，高 44）。5 秒后自动消失；打开弹层时立刻收起。撤回后再弹一条「已撤回，记录已恢复」。

### 4.15 应用锁

可选功能，默认关闭，在设置里开启：生物识别（指纹 / 面容）或手势图案，二者都必须设数字 PIN 兜底。

- **解锁页**：纸面 + 点阵，居中 Logo 圆章（−8°）+ 楷体「家簿已上锁」。生物识别模式进入即拉起系统验证框，下方文字按钮「用 PIN 解锁」。
- **手势图案**：3×3 点阵，点直径 14（触控区 64），连线主色 3 宽、圆头；错误时连线变 neg 色并轻微左右抖动 3 次（减少动态效果时不抖，只显示文字「图案不对，再试一次」）。
- **PIN**：4–6 位，圆点占位；数字键盘按键 64 圆、Sans 24；同样错误提示。
- **何时验证**：启动 App；从后台返回且离开超过设定时长（建议默认 1 分钟）。
- **开启后的隐私**：通知只显示「家簿有新消息」，不含金额与内容；最近任务里的缩略图显示纯纸面 + Logo，不露内容。
- v1 锁的是整个 App，不按空间分别加锁。

### 4.16 聊天里的结构化组件（ChatWeave 默认组件的手账皮肤）

聊天回复由开源库 [ChatWeave](https://github.com/zz-howard/chatweave) 渲染：服务端下发“语义块”（只有数据和含义，没有颜色和尺寸），客户端按块类型选组件。家簿做两件事：① 实现 ChatWeave 的主题接口，把它的中性默认组件换成手账外观；② 注册家簿自己的业务组件（记录卡、资料卡）。本节只规定外观，库的机制见其文档。

总规则：

- **全部水平 0°**：这些组件都含文字和数字，遵守三条硬规则第 1 条；外壳统一是纸面卡片（paper 底、圆角 3、卡片级阴影），**不加胶带**（胶带只留给记录卡等家簿自有卡片，避免满屏装饰）。
- **字体不变**：组件里的标签、表格文字、表单用正文 Sans；数值用 Caveat；手写楷体只用于家簿自己的固定文案（例如“原图已保存”），不用于服务端下发的任何文字。
- **颜色只来自令牌**：语义状态 → 颜色的映射见下表；颜色从不单独承载信息，状态同时有文字标签或图标。
- **最大宽度** 332（与记录卡一致），左对齐在 AI 正文列里。

| ChatWeave 类型 | 家簿外观 |
|---|---|
| `markdown` | 即 AI 正文（4.9）：Sans 15 / 1.7，不加气泡；粗体 Sans 700；链接 primary-text + 下划线；行内代码 surface-2 底；不显示图片 |
| `x-jiabu.record_card` | 记录卡（4.1），家簿自定义组件 |
| `x-jiabu.document_card` | 资料卡（4.1），家簿自定义组件 |
| `metric` | 单张纸面小卡：标签 Sans 12 粗 ink-2；数值 Caveat 40（单位 Sans 13）；变化量 Sans 13 带箭头；评价为状态色文字 + 小图标 |
| `metric_group` | 与“用途账户格子”同一套样式：两列格子，间距 12，数值 Caveat 34；200% 字号时改单列 |
| `dataset` | 横格纸（4.12 的蓝色行线 + 左侧红色装订线），表头 Sans 12 粗 ink-2，行高 ≥ 44；金额列 Caveat 24 右对齐；超过 20 行折叠“展开全部” |
| `time_series` | 纸面卡里的折线：线宽 2、圆头；序列色依次取 1.1 表末的两个图表色令牌，第三条起复用颜色并改用虚线 / 点线区分；坐标轴 line-strong 1px；数值标签 Caveat 14；下方一行 Sans 13 数据摘要；可切到表格视图 |

### 4.17 过程条（AI 正在做什么）

每条 AI 回复的最上方、「家簿助手」署名行之下、正文之上，有一条“过程”：生成中逐行显示 AI 正在做的事，回答写完后自动收起成一行（产品规则见[需求 · 聊天回复](../product/requirements.md#聊天回复文字与组件混排逐步显示)）。它是 ChatWeave 的过程条（`ProcessStrip`）换上手账外观。像手账页边用铅笔记的一串小勾：轻、细、不抢正文。

- **形态**：**水平 0°**（含文字行），**不是纸片卡**：没有纸面底、没有阴影、没有胶带，直接写在纸上。左侧一条 1.5 宽的 line-strong 虚线竖线（像手账的时间轴），每行从竖线右侧 10 开始。宽度跟 AI 正文列一致，最大 332。与下方正文间距 8。
- **展开（生成中）**：每个步骤一行，最小高 32，行距 4：
  - 左侧状态图标 16（`JiabuIcons` 的手绘线条风格，与贴纸图标同一种微抖动线条）+ 步骤说明 Sans 13 ink-2（单行，超长省略号）+ 右侧耗时 Caveat 15 ink-3（如“0.8”，后跟 Sans 12「秒」）。
  - 有结果说明时在说明下方再一行 Sans 12 ink-3（如“找到 23 笔”）。
  - 状态：运行中 = 主色手绘小圆圈转动（“处理中”转圈的小号版本）；完成 = pos 色手绘 ✓；没有完成 = warn 色手绘「!」+ 右侧文字「没有完成」warn 色（不用 neg 红，失败的是一次查询，不是钱出了问题）；等你确认 = primary-text 手绘小指针 + 右侧文字「等你确认」（选项为「等你回答」）primary-text 粗体，整行可点，点后滚动到正文里的确认卡 / 选项；回答后这一行回到运行中，完成后照常打 ✓ 和耗时，并在结果说明那一行写「你已确认」/「你选了：招行信用卡」ink-3；已停止 = ink-3 短横线 + 「已停止」ink-3。
  - 子步骤（以后有子 Agent 时；v1 没有）：在委派那一行下方缩进 16、默认收起，委派那一行右侧写「3 步」+ 小箭头。
- **收起（回答写完后）**：一行高 32（可点区域上下扩到 48）：左侧铅笔小图标 16 ink-3 + 摘要 Sans 13 ink-3，如「查了 3 项 · 用时 4 秒」+ 右侧小下箭头（展开后转为上箭头）。有没完成的步骤时摘要写「查了 3 项（1 项没有完成）· 用时 4 秒」，括号部分 warn 色；数字用 Caveat 15。中途问过你的回复不写总用时（里面有等你的时间），改写「查了 3 项 · 你确认了 1 项」。
- **暂停（等你确认 / 回答时）**：回复停在原地，过程条保持展开，「三点跳动」消失；你回答后同一条回复继续，过程条不重新开始。
- **字体**：步骤说明和结果说明来自服务端，一律 Sans（2.3：楷体只给 App 自己的固定文案）；耗时、计数这些数字用 Caveat。
- **颜色**：只来自令牌；状态不单靠颜色，每种状态都有图标和文字（“没有完成”“等你确认”“已停止”），完成的行有耗时。
- **展开 / 收起**：回答写完那一刻自动收起一次；用户在生成中手动展开或收起过，就不再自动切换。从历史记录打开的回复默认收起。没有步骤的回复不显示过程条。
- **与“三点跳动”的关系**：AI 头像旁的“三点跳动”照常表示回复还在生成；过程条只说明在做哪件事，两者不重复文字。
- **读屏**：收起时读作「过程：查了 3 项，用时 4 秒，已收起，双击展开」；每行读作「查本月餐饮支出，完成，0.8 秒」「对比上月，没有完成，暂时查不到」；竖线、图标对读屏隐藏（状态由文字读出）。回复暂停等你时礼貌播报一次「需要你确认：……」，其余步骤不逐条播报。

### 4.18 等你回答时的输入栏（锁定与“回答”标签）

一条回复停在原地等你回答（4.10 / 4.16 的中断卡）时，底部输入栏跟着变，告诉你“现在打的字算什么”。外观仍是手账：纸面、虚线、便利贴，不做系统风格的灰色禁用条。

- **锁定**（卡片在等回答）：输入栏保持原位、0°。文字框换 surface-2 底，边框改 1.5 虚线 line-strong（像“这里先别写”）；框内左侧手绘向上小箭头 16 ink-3，占位文字「先回答上面的问题」Sans 14 ink-3；有没发出的草稿时写「先回答上面的问题 · 草稿已保留」。发送、拍照按钮 ink-3、禁用。点锁定的输入栏 = 把列表滚到那张卡，并让卡上的「输入其他内容」胶囊闪一次 primary-soft 底（220ms），**不弹键盘**。
- **回答中**（点了「输入其他内容」）：输入栏恢复正常外观并自动聚焦、弹出键盘；文字框正上方贴一张**便利贴标签**：note 底、note-ink 字，高 32，圆角 2，**水平 0°**（含文字），左侧 3 宽 primary 竖条；文字「回答：」Sans 13 粗 + 问题原文 Sans 13（单行，超长省略号；问题取卡片的问题句或标题）；右侧手绘 ✕ 图标 16 note-ink，点击区 48×48。标签与文字框间距 6，左右与文字框对齐。拍照按钮仍禁用（回答只收文字）；发送按钮照常（有文字时主色并转 −8°）。
- **点 ✕**：标签淡出，输入栏回到锁定，已经打的字保留（占位提示变成“草稿已保留”）。
- **发送后**：标签里的问题换成「提交中…」（离线时「已排队，联网后提交」），文字框清空并禁用；卡片按 4.10 显示“提交中”。服务端确认后标签消失、卡片下方出现「你的回答：……」，回复接着往下写。服务端拒绝时回到“回答中”，刚才的字放回文字框，标签下方一行 Sans 12 warn 色写原因。
- **问题被别处关闭**（另一台手机已经回答、过期、你点了停止）：标签消失、输入栏解锁，草稿留在框里变回普通草稿，并弹一条提示条（4.14）「这个问题已在另一台手机上回答」/「这个问题已过期」/「已停止」。
- **动效**：标签出现 = 上移 8 + 淡入（cardIn 220ms），消失 = 淡出 220ms；锁定 / 解锁的边框与底色用 220ms 过渡；“减少动态效果”时直接切换。
- **读屏**：锁定时读「输入框，已锁定，先回答上面的问题」；回答中读「正在回答：用哪张卡付的？」，✕ 读「取消回答，返回选项」；状态变化礼貌播报一次。
- 最终回答里顺带的问题（回复已经结束）不锁输入栏、没有标签。

### 4.19 设置与个人 API key

API key 是给自己的脚本和 agent 用的“钥匙”。界面要做到两点：**一眼看清每把钥匙能做什么、还能用多久、最近有没有人用过**；**明文只出现一次，而且很难被误截屏、误分享**。产品规则见[需求 · 个人 API key](../product/requirements.md#个人-api-key)。

## 5. 动效

| 场景 | 动效 | 时长 / 曲线 |
|---|---|---|
| 底部弹层出入 | 自下而上滑入 + 遮罩淡入 | 260ms，cubic-bezier(.2,.8,.2,1)；遮罩 220ms |
| 提示条 | 上移 16 + 淡入 | 220ms |
| 空间切换 | 内容淡出淡入，配色不变 | 250ms |
| 发送按钮 | 有文字时变主色并转 −8° | 200ms |
| AI 输入中 | 三个点依次跳动 | 1s 循环 |
| 处理中 | 转圈 | 0.8s 循环 |
| 新记录卡出现 | 淡入 + 上移 8 + 胶带从 0 宽“贴上” | 200–250ms，可选 |
| 过程条新增一行 / 展开收起 | 新行淡入；收起与展开用尺寸过渡，箭头旋转 180° | 220ms（同 cardIn） |
| 过程条运行中的步骤 | 手绘小圆圈转动（“减少动态效果”时改为静态铅笔图标） | 0.8s 循环 |
| 输入栏锁定 / 解锁、“回答”标签出入 | 边框与底色过渡；标签上移 8 + 淡入，消失淡出 | 220ms（同 cardIn） |

规则：动效只解释“东西从哪来、到哪去”，不做弹跳和长动画；任何动效不得延迟用户可以点击的时间。

**减少动态效果**：跟随系统“移除动画”设置（Flutter 中读 `MediaQuery.disableAnimationsOf(context)`）。开启时所有过渡改为直接出现，转圈改为静态“处理中”图标，打字点不动；倾斜角保留（它们是静态装饰）。v1 不在 App 内单独提供开关。

## 6. 无障碍

- 正文对比度 ≥ 4.5:1，大字（≥ 24 或 ≥ 18.7 粗）≥ 3:1；ink-3 是最浅的文字色。
- 可点击区域 ≥ 44×44（Android 建议 48dp；Flutter 的 Material 组件默认 48×48，自绘控件用 `ConstrainedBox` 保证最小 48）。
- 最小字号 12；支持系统字体放大到 200%：列表行、卡片必须能长高，金额允许换行而不是被截断。
- 颜色不单独承载信息：负数有“−”号和「超支」标签，空间有名称文字（点缀色不单独承载信息），状态有文字。
- 读屏：金额读作“支出 68 元”而不是“负号 人民币 68.00”；贴纸、胶带、手绘圈、波浪线全部对读屏隐藏；印章读作状态（“已记录”）。图表需提供包含全部数值的文字描述。
- 倾斜元素的点击区域按未倾斜的矩形计算。
- 手写字只做装饰性短文案；任何关键信息都能在正文字体里找到。

## 7. Flutter 实现要点

设计系统做成独立的 `jiabu_design` 包：页面代码不许直接写色值、字体和时长，只能从这个包里取。所有颜色、尺寸、角度、时长数值以前文为准。

### 7.1 主题与颜色

用 **ThemeData + ThemeExtension**：ThemeData 是 Flutter 整个 App 的“主题对象”，Material 组件自动从它取颜色和字体；ThemeExtension 是挂在主题上的“自定义令牌包”，用来放 Material 本身没有的手账专用颜色（胶带、便利贴、荧光笔等）。

```dart
@immutable
class JiabuColors extends ThemeExtension<JiabuColors> {
  const JiabuColors({required this.bg, required this.paper, required this.ink, required this.ink2, required this.ink3,
    required this.primary, required this.primaryText, required this.primarySoft, required this.onPrimarySoft,
    required this.highlight, required this.note, required this.noteInk, required this.tapeA, required this.tapeB /* … */});
  final Color bg, paper, ink, ink2, ink3, primary, primaryText, primarySoft, onPrimarySoft, highlight, note, noteInk, tapeA, tapeB;
  @override JiabuColors copyWith({/* … */});
  @override JiabuColors lerp(JiabuColors? other, double t) => /* 每个颜色 Color.lerp */;
}
const jiabuColors = JiabuColors(bg: Color(0xFFF6EFE2), paper: Color(0xFFFFFDF7), primary: Color(0xFFB4532D), /* … */);
// 空间点缀色：固定色板，按 key 存库（spaces.accent_color），客户端查表取色
const spaceAccents = <String, Color>{'terracotta': Color(0xFF9C4423), 'indigo': Color(0xFF3B5A8C), /* … 共 8 色 */};
// 只有 tokens/colors.dart 里允许出现 Color(0x…)；业务代码一律 context.jiabu.colors.primary
```

两层结构：① Material 3 的 `ColorScheme`（纸色、墨色、主色映射到 surface / onSurface / primary）和 `TextTheme`，让 Material 组件自动带上手账配色；② `JiabuColors`、`JiabuType`、`JiabuDecor`（胶带色、两层阴影参数、倾斜系数）、`JiabuMotion`（时长、曲线）四个 ThemeExtension。

全 App 只有一套 ThemeData，切换空间不换主题。当前空间的点缀色由当前空间状态提供（`currentSpaceProvider` → `spaceAccents[space.accentKey]`），只交给 `SpaceSwitcher`、空间列表圆点和记录卡角标使用；业务组件不许用点缀色画底色或按钮。不要用 Material 的动态取色（Material You），它会冲掉品牌色。

### 7.2 字体

全部打包进 App，绝不运行时下载。在 `jiabu_design` 的 `pubspec.yaml` 里声明，并**显式写字重**（Flutter 不会从文件名推断字重）：

```yaml
flutter:
  fonts:
    - family: Caveat
      fonts: [{ asset: assets/fonts/jiabu_numerals.ttf, weight: 600 }]   # Caveat SemiBold
    - family: JiabuHand
      fonts: [{ asset: assets/fonts/jiabu_hand.ttf, weight: 500 }]       # LXGW WenKai Medium 子集
    - family: NotoSerifSC
      fonts: [{ asset: assets/fonts/jiabu_serif.otf, weight: 700 }]      # Noto Serif SC Bold 子集
```

数字 + 中文混排（“今天 12:36”）：首选 `TextStyle(fontFamily: 'Caveat', fontFamilyFallback: ['JiabuHand'])`，即“字体回退链”，Caveat 没有的字（中文）自动落到楷体；在真机上是否稳定要靠截图测试验证。若不稳定，按字符类别拆成多个 `TextSpan`（一段文字里可单独指定字体的一小段），数字 / 符号段用 Caveat、中文段用 JiabuHand。两种做法都封装在 `HandText(text)` 组件里。金额同理：`¥` 和小数部分用单独的 `TextSpan`，字号按 0.55–0.72 倍缩小，由 `AmountText` 组件统一处理。

金额列对齐：先确认 Caveat 字体含 `tnum`，有则用 `fontFeatures: [FontFeature.tabularFigures()]`；没有则金额列右对齐即可。

### 7.3 纸面与点阵背景

用 `CustomPainter`（Flutter 里“自己拿画笔在画布上画”的方式）画纸面：

```dart
class DotPaperPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    canvas.drawRect(Offset.zero & size, Paint()..color = colors.bg);
    const step = 18.0, r = 1.1;          // 逻辑像素，与上文一致
    final dot = Paint()..color = colors.dot;
    for (/* x */ …) for (/* y */ …) canvas.drawCircle(Offset(x, y), r, dot);

```

更省的做法：先画一块小图块，再用 `ImageShader` 平铺，不在每帧循环画几千个圆。横格纸（列表）：`canvas.drawLine` 画行线 + 左侧 30 处红色装订线。主卡的方格纸同理。

### 7.5 倾斜

用 `Transform.rotate`（只旋转绘制，不改变布局占位和点击区域），旋转原点为元素中心。角度用确定性哈希计算：

```dart
double tiltFor(String id, {double amp = 1}) {
  var h = 7;
  for (final c in id.codeUnits) { h = (h * 31 + c) % 997; }   // UTF-16 码元
  return ((h % 5) - 2) * 0.45 * amp;       // 单位：度
}
```

加一个测试：用一组固定 id 和预先导出的期望值（JSON 夹具）断言输出不变。**禁止**给 `ListView` 的行、记录卡、格子、表单加旋转；业务代码只能通过 `jiabu_design` 的 `Tilt` 组件旋转。

### 7.6 阴影与贴纸白边

Material 的 `elevation` 阴影偏灰偏硬，不用。纸片阴影用 `BoxDecoration(boxShadow: [...])` 写成 3.3 的两层阴影（`BoxShadow(offset, blurRadius, spreadRadius, color)` 与 CSS 的 x y blur spread color 一一对应）；形状不规则时在 `CustomPainter` 里用 `canvas.drawShadow` 或带 `MaskFilter.blur` 的画笔自绘。贴纸白边：`Border.all(width: 2.5, color: Colors.white)` + 圆形 + 自绘阴影 + `Transform.rotate`（−6°）。

### 7.7 手绘线条（导航圈、标题波浪线、铅笔划线、贴纸图标）

所有手绘路径（导航圈、波浪线、约 40 个贴纸与界面图标）统一放在中立的 `tool/icons/icons.json`（路径数据 + 线宽 + 视口），由脚本**生成 Dart `Path` 代码**，用 `CustomPainter` 描边（`Paint()..style = PaintingStyle.stroke..strokeCap = StrokeCap.round`）。不用 Material Icons 或第三方图标库替代——要求“形状一样”，不是“长得像”；`flutter_svg` 只留给将来的插画。已撤销的划线：一条 2 宽、旋转 −2.5° 的线横穿金额。

### 7.8 其他

- 底部弹层：`showModalBottomSheet`，拖拽把手为胶带组件，`backgroundColor = paper`，顶部圆角 20。
- 提示条：`ScaffoldMessenger` + 自定义外观的 `SnackBar`；撤销动作 5 秒。
- 筛选 chip：`FilterChip` 改外观（虚线边框需在 `CustomPainter` 里按虚线分段描 `RRect`，Flutter 没有内置虚线边框）。
- 动效时长统一从 `JiabuMotion` 取（`sheet 260ms Cubic(.2,.8,.2,1)`、`scrim 220ms`、`snack 220ms`、`space 250ms`、`send 200ms`、`cardIn 220ms`），优先用隐式动画（`AnimatedContainer`、`AnimatedRotation`、`AnimatedOpacity` 等：改变目标值，框架自动补帧）；只有“三点跳动”“转圈”这类循环动画用 `AnimationController`。
- 减少动态效果：`MediaQuery.disableAnimationsOf(context)` 为真时 `JiabuMotion` 把所有时长设为 0，循环动画换成静态图标；倾斜角保留。
- 可点击区域：Material 组件默认最小 48×48（`MaterialTapTargetSize.padded`）；自绘按钮用 `ConstrainedBox(minWidth: 48, minHeight: 48)` 保证。
- 横向滚动的 chip 行不能引起整页横向滚动；整页在 360 宽不得横向滚动。
- 深色模式：v1 不做深色主题（手账纸面是品牌核心）；系统深色时保持浅色纸面，仅状态栏图标反色。
- ChatWeave 主题接口：在 App 里写一个 `JiabuChatWeaveTheme`（放在 `app/lib/shared/chatweave/`，**不放进 `jiabu_design`**，让设计系统包不依赖 ChatWeave），从 `JiabuColors`、`JiabuType`、`JiabuDecor`、`JiabuMotion` 取值生成 ChatWeave 的主题数据：状态色按 4.16 映射，`blockFrame` 用 `PaperCard`（0°），图标用 `JiabuIcons`，动效时长取 `JiabuMotion`。它只引用令牌，不出现颜色或字体字面量；4.16 的组件同样纳入 golden 与几何断言（宽 332、0°）。过程条（4.17）通过 ChatWeave 的 `processStripBuilder` 换成家簿实现 `JiabuProcessStrip`（同目录），同样只引用令牌，并纳入 golden（运行中 / 全部完成 / 有没完成 / 等你确认 / 回答后完成并显示回答 / 暂停中停止 / 已停止 / 收起）与几何断言（0°、最大宽 332、行高 ≥ 32、收起时可点区域 ≥ 48）。设置页与 API key（4.19）、“通过 API key”标注（4.20）同样纳入 golden（有效 / 将到期 / 永不过期 / 已撤销 / 已过期的行、新建弹层含风险便签、只显示一次、详情、撤销确认、带钥匙标注的记录卡与详情）与几何断言（key 卡与选择卡 0°、钥匙贴纸 −6°、「我」圆章 0° 且点击区 ≥ 48）；等宽字体只允许出现在 4.19 的两处（`check_rules` 检查 `JiabuType.mono` 的使用位置）。输入栏的锁定与“回答”标签（4.18）接 ChatWeave 的 `InterruptComposerController`，标签用家簿的 `JiabuAnswerChip` 替换 ChatWeave 的 `InterruptAnswerChip`（同目录，只引用令牌），纳入 golden（锁定 / 锁定且有草稿 / 回答中 / 提交中 / 已排队 / 被拒绝）与几何断言（标签 0°、高 32、✕ 点击区 ≥ 48）。
- 验证方式：每个界面状态生成 **golden 截图测试**（把界面渲染成图片，与已批准的基准图逐像素比对，有变化即报警），只在固定工具链里生成；再加“几何断言”（直接断言关键元素的位置、尺寸、角度等于本规范的数值，如记录卡宽 332、胶带 −5°、上沿 −10、印章 −5°、贴纸 −6°）。详见 [客户端规范 · 测试与质量关卡](../engineering/client-flutter.md#6-测试与质量关卡)。

## 8. 验收清单（给开发和测试）

- 360dp 与 430dp 宽：无横向滚动、无文字被裁一半（允许单行省略号）。
- 所有可点元素 ≥ 44dp（建议 48）。
- 每种字体只显示它覆盖的字：手写样式文案中出现子集外的字 → 构建失败。
- 空间切换：配色不变，顶栏名称与点缀色圆点更新；切换后只显示新空间的记录、账户、资料和聊天，旧空间内容不残留。
- 空间列表只出现本人在册的空间；默认个人空间无邀请入口。
- 已退出成员创建的记录显示「名字 · 已退出」。
- 应用锁开启后：冷启动和超时返回都要求验证；通知不含内容；最近任务缩略图被遮挡。
- 记录卡、列表、格子、弹层、提示条 0° 倾斜。
- 聊天里的结构化组件（4.16）0° 倾斜、无胶带；组件出现时上方已显示的文字不跳动；不认识的组件显示文字说明。
- 等你回答时（4.18）：输入栏锁定、占位「先回答上面的问题」、发送和拍照不可用、草稿不丢；每张中断卡都有「输入其他内容」；点它后输入栏解锁并挂「回答：……」便利贴标签（0°），✕ 回到锁定且草稿还在；发出的文字只出现在卡片上，不出现我的便利贴气泡；问题在另一台手机上被回答后标签消失并有提示条。
- 过程条（4.17）0°、无纸面卡和胶带；生成中逐行展开，回答写完后自动收起成一行、点按可展开；没完成的一步只在自己那一行标「没有完成」；「等你确认」可点并滚动到确认卡；不显示查询条件、原始数据和 AI 的思考原文；200% 字号下说明可换行、不裁字。
- 设置入口（4.19）：三个主界面顶栏右侧都有「我」圆章，0°，点击区 ≥ 48；底部导航仍只有三项。
- API key（4.19）：新建时选「永不过期」出现风险便签；新建表单里没有选空间的项；完整 key 只在「只显示一次」页出现，该页不能下拉关闭、禁止截屏，关闭后任何地方都看不到完整 key；列表显示开头几位、权限、到期和最近使用；已撤销 / 已过期的 key 在「已失效」组里并有灰色印章；离线时不能新建或撤销；权限卡下方有「API key 不能和 AI 对话……直接生效」的说明。
- 通过 API key 的记录（4.20）：记录卡、详情、变更记录和历史行都有钥匙标注，读屏读出「通过 API key：名称」。
- 开启“移除动画”后无任何动画。
- TalkBack（安卓读屏）能完整读出一条记录：类别、标题、金额、账户、状态。
