# V4 原稿还原交付说明（历史）

日期：2026-10-30  
分支：`v4-history-restore`

依据：`design-gap-audit-2026-10-30` 的历史表与 V4 批次、原稿 `prototype-v1/style-d.html` 的 `history()`、`row()` 与 `.search / .fchips / .fchip / .list.ruled / .li / .hs-day` 样式、Howard 的原稿历史截图，以及 Howard 报告的问题：筛选 chip 行最后一个「时间」滑到最右也看不全。Howard 已同意历史页回到原稿。

## 改动

- **chip 行看不全（Howard 报告）**：原因是 chip 行右侧一直盖着一段 32 宽的渐隐，而且滚动内容右边没有留白，滚到底时最后一个 chip 正好贴着（被盖在）渐隐下面。现在 chip 行左右通到屏幕边（原稿 `.fchips` 的 `margin: 0 -18px; padding: 0 18px`），首尾各留一个页边距（360 宽 14、430 宽 18）；渐隐（24 宽）**只在那一侧还有没露出的 chip 时出现**：没滚动时只有右侧，滚动中两侧，滚到底只有左侧。`PaperChipScroller` 按滚动位置（`extentBefore / extentAfter`）切换，滚到底后最后一个 chip 完整可见、右边留页边距、点它的中心就是点它本身。
- **搜索卡**：`PaperSearchCard`：paper 底、圆角 12、line 细边 + 浅纸片阴影，最小高 52，左侧 20 放大镜，无边框输入框，字下一条 rule 细线（原稿 `.search`）。原来是直角细黑线框 + 浮动标签。
- **筛选 chip**：`PaperFilterChip` 改为自绘：高 44、圆角 8、Sans 15 / 600，每个都带 16 的 ⌄；未选 1.5 虚线 + 80% paper 底；选中 primary-soft 实底 + 2 白圈 + 贴纸阴影 + ✓。读屏是按钮 + 选中状态。
- **每天一张纸卡**：日期胶带和当天「支出 ¥…」（Sans 13 ink-3 + Caveat 17，当天没有支出时不显示）放到卡片**上方**；胶带文字改成原稿的「10月28日 周三」（`Oct 28 Wed`，非当年带年份）。卡片 paper、圆角 3、卡片级阴影、0°，行与行之间 rule 细线（`PaperTimelineCard`）。
- **时间线**：1.5 宽红线从卡片顶到底，x = 12 + 20，穿过每行 40 圆形贴纸的中心，贴纸压在线上；原来是窄栏装订线，贴纸不压线。
- **行**（`LedgerHistoryRow`）：贴纸 → 标题（最多两行）/「账户 · 类别」（真实账户 · 用途账户；没有用途账户用第一个标签；转账 / 调拨写类别）→ 右侧带符号的 Caveat 600 金额 24（支出 −¥ 墨色、收入 +¥ 绿色，沿用 V1），下面一行 Caveat 15 ink-3 的**记下时间**。成员名不再出现在行里。状态与 API key 钥匙仍在左栏下面。
- **记下时间**：用记录的 `created_at`（本机时区、24 小时制）。记录本身只有日期，所以这是“什么时候记的”，不是“什么时候花的”；没有 `created_at` 时不显示。同一天内按记下时间从新到旧排（`filterHistory`，原来同一天按 id 排，时间会乱跳）。
- **贴纸跟标签**：支出的贴纸按第一个预设标签选（餐饮 / 买菜 → 饭碗，交通 → 帐篷，住房 / 日用 → 房子，医疗 → 心，教育 → 书，娱乐 → 爱好），其余按种类。记录卡、总览近期变化同一规则（`recordStickerCategory(row, snapshot:)`）。
- **空状态**：放大镜 + 楷体「没有找到符合条件的记录」（规范原文；原来是吉祥物）。
- **设计包**：新 `history_decor.dart`（`PaperSearchCard`、`PaperChipScroller`、`PaperTimelineCard`），`PaperFilterChip` 重写，`JiabuLedgerMetrics` 新增搜索 / chip / 时间线尺寸。
- **规范**：`docs/design/design-spec.md` 文件头 V4 一条（注明推翻 4.12 原写法），4.0 设置分组一句、4.12 重写、4.20 钥匙位置、7.3 一句、8 验收清单补历史项。没有新文案，手写字没有新字符（胶带只用到已有的月 / 日 / 周 X），字体子集不变。

## 暂不还原 / 需要确认

- 原稿 chip 行最前面的「家庭」实底范围 chip（−2°）：现在空间徽章在页头右上（V2），chip 行里不再重复。
- 选中 chip 的文字仍是「账户」「类型」，没有改成原稿那样显示选中的值（如「招行卡 ⌄」）。
- 时间旁原稿的家庭 / 私人小图标：多空间后不再有固定的两种范围，未加。
- 记下时间 vs 发生时间：见上，若希望没有时间也可以一行删掉。
