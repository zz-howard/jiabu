## V1 数字与金额

- **字重实测（审计里的 R6 假设不成立）**：`jiabu_numerals.ttf` 是从 Caveat[wght] 在 600 实例化后裁剪的**静态**字体（无 fvar，OS/2 usWeightClass = 600），不存在“可变字体默认落在 400”的问题。构建机上用 Flutter 渲染 120px 的「¥21,103.90」数墨量：w400 / w500 / w600 / w700 请求都是 9643 像素（同一个静态文件，没有合成粗体），w800 才会被合成加粗（13989）；对照 fontTools 实例化的 Caveat：400 → 7621、600 → 10283、700 → 11551（PIL 度量，同一文本），渲染值贴近 600。原稿 prototype-v1 内嵌的 Caveat 子集也是 600，墨量与我们的文件相差 0.7%。结论：字重本来就对，金额“看着细”是字号（总览主卡 40 而不是 62）和渲染对比，不是字体。已加回归测试 `numerals_weight_test.dart`：静态 600、渲染落在 600 带内、主题里没有 ≥ w800 的 Caveat 样式。
- **金额写法**：`AmountText` 新增 `tone`（auto / plain / positive）和 `showPlus`。记录金额一律通过 `recordAmount(...)`：支出「−¥68.00」墨色（不再红色）、收入 / 退款 / 月度拨入「+¥」绿色、转账不带符号；负余额仍是红色。聊天记录卡、详情、历史行、总览近期变化一致。账户余额和列表金额改为普通墨色，主卡 / 详情 / 记录卡金额为主色（原稿如此）。
- **荧光笔**：记录卡金额、详情大金额、总览汇总卡的总余额数字加下半截荧光笔（组件早已有，页面从未启用）；已撤销的记录不高亮。

## V2 页面标题块与空间徽章

- 新增 `JiabuPageTitleBlock`（Serif 标题 + `HandUnderline` 手绘波浪线 + Caveat 英文点缀 + 楷体副标题）、`JiabuHomeMark`（聊天页的圆形家徽）、`SpaceBadge`（右上角空间徽章，见下）。
- 聊天 / 总览 / 历史三页的标题由 `MainFrame` 页头统一给出（页面本体不再写标题），设置页由 `JiabuPageHeader` 的 `subtitle` 参数使用同一个标题块。副标题：聊天「My Home Diary · 家人可见」（个人空间「仅自己可见」）、总览「Oct. 29 · Thu · 这个月的小账本」、历史「Diary Log · 账目与家庭资料」、设置「Settings · 账号、空间与安全」。新增 7 条 arb 文案（中英），手写字子集重新裁剪（`subset.py`，只有 `jiabu_hand.ttf` 和 manifest 变化）。
- **右上角空间徽章**：占原稿「家庭 / 私人」开关的位置，用同样的虚线框 + 选中态药丸（−2°、白描边、阴影）；药丸底色是该空间的点缀色（8 色之一，白字对比 ≥ 5:1），图标共享空间是小房子、个人空间是小锁，右侧小箭头，点开原有「我的空间」弹层（切换空间、新建、空间设置、收到的邀请）。点缀色的“不整屏换色”规则不变，只是从名称文字色变成徽章底色。
- 二级页面（设置、空间、邀请等）不再有页头的空间条，只有自己的返回式页头（设置页带标题块）；大字号（> 140%）时徽章换到标题下方，副标题不绘制但仍在读屏顺序里。
- **「我」圆章取消**：右上角让给空间徽章，设置入口改为底部导航第四项「我的」（小人图标，Howard 2026-10-30 定；徽章底色保持空间点缀色）。
